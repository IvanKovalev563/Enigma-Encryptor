# Enigma Code

A lightweight C# WinForms application for real-time text encryption and decryption using a custom alphabet-substitution algorithm and multi-digit security keys.

---

## Features

* **Custom Substitution Cipher:** Encrypts text dynamically using positional character transformation and user-defined numeric keys.
* **Real-time Processing:** Instant encryption and decryption as you type in text fields.
* **Auto-Key Embedding:** Appends encoded key metadata for streamlined decryption workflows.
* **Localization & Themes:** Full support for English / Russian languages and Dark / Light UI themes.

---

## Tech Stack

* **Language:** C# (.NET Framework 4.7.2)
* **UI Framework:** Windows Forms (WinForms)
* **Settings:** User-scoped properties for persistence (`Settings.Default`)

---

## Quick Start

1. Open `Enigma Code.sln` in **Visual Studio**.
2. Build and run the project.
3. Enter a numeric key, type your message in the **Encryption** field, and copy the obfuscated output.
